# 광고(Google AdSense) 도입 가이드

코드는 준비되어 있습니다. **환경변수만 넣으면 광고가 켜지고, 비워두면 광고 관련 외부 요청이 전혀 없습니다.**
아래는 코드 밖에서 사람이 해야 하는 일입니다. (AdSense 정책/화면은 자주 바뀌므로 가입 시 안내 문구를 우선하세요.)

## 1. 먼저 갖춰야 할 것 (승인 전)
- [ ] **본인 소유 도메인**: 호스팅이 주는 기본 주소(`*.koyeb.app` 등)보다 직접 구입한 도메인을 권장합니다.
      승인 신청과 `ads.txt` 인증이 도메인 기준입니다.
- [ ] **개인정보처리방침 페이지**: 광고 쿠키/기기 정보 사용 고지가 필요합니다. 현재 사이트에는 이 페이지가 **없습니다**.
      (법적 문구는 직접 작성하거나 검토하세요 — 이 저장소에는 포함하지 않았습니다.)
- [ ] **연락처/운영자 정보**: 푸터 또는 별도 페이지.
- [ ] **게임 설명·규칙 같은 텍스트 콘텐츠**: 지금은 방 목록과 게임 화면뿐이라 "콘텐츠가 부족한 사이트"로 반려될 수 있습니다.
      게임 소개/규칙/FAQ 페이지를 두는 것을 권장합니다.
- [ ] 만 18세 이상 구글 계정, 수취용 은행 정보(세금 정보 포함)

### 서브도메인(예: `game.example.dev`)으로 운영하는 경우
- AdSense 사이트 목록에는 **루트 도메인(`example.dev`)만 추가**합니다. 본인 도메인의 서브도메인은 따로 추가하지 않고
  루트 사이트에 포함됩니다. (공식 안내: [사이트 관리 변경](https://support.google.com/adsense/answer/12170421))
- **`ads.txt` 는 루트 도메인(`example.dev/ads.txt`)에 있어야 합니다.** 이 앱이 제공하는 `/ads.txt` 는 게임 서브도메인에만
  적용되므로, 루트 도메인에도 같은 한 줄을 올려야 합니다:
  `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
  (서브도메인에서 다른 게시자 ID/판매자를 쓸 때만 루트에 `subdomain=game.example.dev` 선언이 필요합니다.
  [ads.txt FAQ](https://support.google.com/adsense/answer/9785052))
- **심사는 루트 도메인 기준**으로 진행되므로, 루트 도메인에 아무것도 없거나 개발용 임시 페이지뿐이면 반려될 수 있습니다.
  루트에 간단한 소개 페이지(서비스 소개, 개인정보처리방침, 연락처)를 두세요.
- 같은 루트 아래 다른 서브도메인에 테스트/미완성 페이지가 있으면 사이트 전체 평가에 영향을 줄 수 있습니다(추정).

## 2. 신청 → 승인
1. https://adsense.google.com 에서 가입하고 **사이트(도메인)를 추가**합니다.
2. 소유권 확인: 이 프로젝트는 `ADSENSE_PUBLISHER_ID` 를 설정하면 `/ads.txt` 를 자동 제공합니다
   (`google.com, pub-XXXX, DIRECT, f08c47fec0942fa0`). 안내에 따라 **ads.txt 방식**으로 확인하세요.
3. 심사 대기: 며칠~몇 주. 승인 전에도 `ADSENSE_PUBLISHER_ID` 만 먼저 넣어 `ads.txt` 를 열어둘 수 있습니다.

## 3. 광고 단위 만들기 (승인 후)
AdSense → 광고 → 광고 단위별 → **디스플레이 광고(반응형)** 2개를 만듭니다.
| 용도 | 위치 | 환경변수 |
|---|---|---|
| 로비 배너 | 방 목록 위 | `ADSENSE_LOBBY_SLOT` |
| 게임 종료 배너 | 결과 화면 | `ADSENSE_GAME_END_SLOT` |

각 광고 단위의 **광고 슬롯 ID**(숫자 10자리 안팎)를 복사합니다.

## 4. 환경변수 설정 후 재배포
```
ADSENSE_PUBLISHER_ID=ca-pub-1234567890123456   # AdSense 계정의 게시자 ID
ADSENSE_LOBBY_SLOT=1111111111
ADSENSE_GAME_END_SLOT=2222222222
```
- 게시자 ID 형식이 `ca-pub-숫자` 가 아니면 광고가 표시되지 않습니다(오타 방지).
- 재배포 후 확인: `https://내도메인/ads.txt` 가 열리는지, 로비에서 광고 영역이 보이는지.
  승인 직후에는 광고가 비어 보이는 경우가 있어 수 시간~하루 걸릴 수 있습니다.

## 5. 지켜야 할 것 (계정 정지 방지)
- **본인 광고를 클릭하거나 지인에게 클릭을 부탁하지 마세요.** 가장 흔한 정지 사유입니다.
  개발/테스트 환경에서는 위 환경변수를 비워두세요.
- **게임 플레이 중 화면에는 광고를 넣지 않았습니다.** 오클릭을 유발하는 배치는 정책 위반입니다.
  결과 화면의 광고도 "다시 하기/로비로" 버튼과 충분히 떨어져 있는지 실제 기기에서 확인하세요.
- 한국 사용자 대상이면 개인정보처리방침 고지로 충분한 경우가 많지만, **EEA/영국 사용자까지 받는다면
  동의 관리(CMP) 도입이 필수**입니다.

## 6. 현실 점검
- 트래픽이 적으면 수익이 매우 작고, **지급 기준 금액**(보통 100달러 안팎, 계정 화면에서 확인)에 도달해야 지급됩니다.
- AdSense 승인이 어렵다면 대안으로 국내 광고 플랫폼(예: 카카오 애드핏)이 있지만, 별도 연동 코드가 필요합니다.
